# YouTube Music Downloader (유튜브 음악 다운로더)

유튜브에서 음악을 검색하고 선택한 여러 곡들을 MP3 또는 FLAC 형식으로 일괄 다운로드할 수 있는 편리하고 세련된 윈도우 데스크톱 GUI 애플리케이션입니다. 개인용 MP3 플레이어에 음악을 저장해 오프라인으로 감상하고자 하는 사용자를 위해 최적화되어 있습니다.

---

## ✨ 주요 기능

*   **유튜브 검색 지원:** 영상의 URL 링크를 매번 찾을 필요 없이 검색창에 키워드(예: 곡명, 가수명)를 입력하여 유튜브 영상을 검색할 수 있습니다.
*   **다운로드 대기열 (Queue):** 검색 결과 목록에서 여러 곡을 선택(체크)해 대기열에 한 번에 담아둘 수 있습니다.
*   **유튜브 링크 직접 추가:** 특정 유튜브 URL 주소를 대기열에 즉시 추가하여 백그라운드에서 정보가 비동기로 자동 분석되도록 지원합니다.
*   **일괄(배치) 순차 다운로드:** 대기열에 쌓인 음악들을 백그라운드 스레드에서 차례대로 일괄 다운로드하여 변환합니다. (다운로드 중에도 UI가 멈추지 않습니다.)
*   **다양한 오디오 포맷 지원:** 개인 플레이어 사양에 맞추어 포맷을 선택할 수 있습니다.
    *   **MP3** (고음질 320kbps / 256kbps / 192kbps 비트레이트 선택 가능)
    *   **FLAC** (무손실 압축 음원 포맷)
*   **완료된 음악 재생 및 관리:** 다운로드 완료 탭에서 바로 재생 버튼을 눌러 기본 미디어 플레이어로 청취하거나, 필요 없는 파일을 삭제하고, 보관함의 파일을 일괄 삭제할 수 있습니다.
*   **폴더 열기:** 다운로드 폴더(`c:\Personal\youtube_down`)를 윈도우 탐색기로 원클릭 오픈할 수 있습니다.

## 🛠️ 준비 사항

프로그램이 유튜브 음원을 추출하고 인코딩하는 과정에서 **FFmpeg**를 사용하므로 아래의 조건이 필요합니다.

1.  **Python:** 시스템에 Python 3.8 이상 버전이 설치되어 있어야 합니다.
2.  **FFmpeg:** 시스템 환경 변수(PATH)에 `ffmpeg`가 등록되어 있어야 합니다.
    *   *확인 방법:* 명령 프롬프트(CMD) 또는 PowerShell에서 `ffmpeg -version` 명령어가 정상 동작해야 합니다.

## 🚀 설치 및 실행 방법

### 방법 1: 단일 실행 파일로 실행하기 (가장 간편함)

1.  프로젝트의 `dist/` 폴더 내에 빌드된 `YoutubeDownloader.exe` 파일을 원하시는 폴더로 복사합니다.
2.  `YoutubeDownloader.exe` 파일을 더블 클릭하여 바로 실행합니다.

### 방법 2: 배치 파일을 활용한 개발/실행 모드

1.  이 리포지토리를 다운로드(클론)합니다.
2.  루트 디렉터리에 있는 `run_app.bat` 파일을 더블 클릭해 실행합니다.
    *   *배치 파일이 자동으로 파이썬 가상환경(`.venv`)을 생성하고, 필요한 모든 종속성 라이브러리를 설치 및 업데이트한 뒤 앱을 구동합니다.*

---

## 📦 단일 `.exe` 프로그램으로 직접 빌드하기

프로그램의 수정한 코드를 포함하여 다른 PC나 환경에서도 파이썬 없이 바로 실행할 수 있는 `.exe` 파일로 다시 패키징하고 싶다면 아래의 배치 파일을 실행하세요.

1.  프로젝트 루트에 있는 `build_exe.bat` 파일을 실행합니다.
2.  빌드가 완료되면 **`dist/YoutubeDownloader.exe`** 파일이 생성됩니다.

## 📝 파일 구성 설명

*   `gui_app.py`: CustomTkinter 기반의 GUI 디자인 및 핵심 비즈니스 로직(검색, 백그라운드 다운로드 큐, 파일 재생/삭제 등)이 포함된 메인 파이썬 스크립트입니다.
*   `requirements.txt`: 앱 작동 및 빌드에 필요한 라이브러리 목록 (`customtkinter`, `yt-dlp`, `pyinstaller`, `pillow`)이 포함되어 있습니다.
*   `run_app.bat`: 원클릭 가상환경 설치 및 애플리케이션 실행 런처 배치 스크립트입니다.
*   `build_exe.bat`: CustomTkinter의 정적 에셋 데이터를 포함하여 단일 `.exe` 프로그램으로 빌드해 주는 배치 스크립트입니다.
*   `implementation_plan.md`: 애플리케이션 개발 당시 작성된 상세 구현 계획서입니다.
